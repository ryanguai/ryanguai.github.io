Projects

AI Research Paper Q&A Agent

A RAG system that answers questions about ~500 recent arXiv papers on retrieval-augmented generation, citing the specific paper and section. Declines to answer when the corpus doesn't support a confident response.

Architecture

arXiv API ──▶ PDF Parser ──▶ Section Chunker ──▶ BGE-small ──▶ ChromaDB (500 papers) (PyMuPDF) (by section) (384-dim) (28K chunks) Question ──▶ Retriever ──▶ Generator ──▶ Cited Answer │ ├─ Paper title + arXiv ID ├─ Vector: cosine sim ├─ Section reference └─ Hybrid: BM25 + RRF └─ "I don't know" path

What didn't work and how I fixed it
Infinite loop in chunker. Section-aware chunking hit 100% CPU on large papers — the sentence splitter's overlap logic didn't advance when overlap exceeded chunk size. Fixed with a minimum-advance guard.
Vector search lacked diversity. Top-10 results clustered around one sub-topic (e.g., 3 chunks from the same paper). Adding BM25 keyword search with Reciprocal Rank Fusion brought in results from different papers and research angles.
